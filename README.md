# 通販服試着

**「この服を買ったら、手持ちで何通り着られる？」**

通販で気になったトップスを、手持ちのボトムスと合わせて試せるWebアプリです。着用イメージを横並びで見比べて、気に入った組み合わせだけを保存できます。

## 初版の使い方（予定）

1. 手持ちのボトムスを履いた正面写真を、名前と一緒に登録する。
2. 通販で気になったトップスの商品画像を1枚アップロードする。
3. 合わせたいボトムスを登録一覧から最大3着選び、試着イメージを生成する。
4. 着用イメージを見比べ、気に入ったコーデを保存する。

たとえば、通販の白シャツを手持ちのデニム、黒スラックス、ベージュチノと合わせて比較し、気に入った2通りだけを保存できます。

## 開発状況

現在は仕様を検討している段階です。試着画像の生成には Perfect Corp. の YouCam API「服バーチャル試着」を使う予定です。まずはトップス2着とボトムス3着の計6パターンを試し、元のボトムスの色や形が生成後も判別できるかを確認します。
